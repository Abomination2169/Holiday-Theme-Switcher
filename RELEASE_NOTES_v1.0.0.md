# Holiday Theme Switcher v1.0.0

For Meta Quest and Beat Saber `1.40.8_7379`.

- Choose Default, Halloween, Thanksgiving, Christmas Eve, New Years, or Dynamic.
- Christmas Eve replaces the original Christmas theme. It includes layered snowfall, snowdrifts, a mountain backdrop, and the results-screen aurora.
- Dynamic mode selects Christmas Eve from December 1–30 and New Years from December 31 through January 31.
- Switching themes shuts down the outgoing seasonal particles before starting the next theme.
- Saved original Christmas selections open Christmas Eve.

Install the release QMOD using your Quest mod installer. Disable standalone seasonal QMODs while using the switcher.
